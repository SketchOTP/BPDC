# Project Goal

## Lifecycle

- Status: `ADOPTED`
- Last verified: 2026-08-22 America/New_York

## Goal

Build an original persistent desktop creature that creates a believable illusion of autonomous life on the user's computer without being an AGI, chatbot mascot, or artificial-life claim.

## Objective success criteria

- The creature has persistent internal state, autonomous motivation, personality, memory, habits, environmental awareness, expressive animation, passage of time, and long-term development.
- Behavior is believable rather than merely intelligent: coherent, imperfect, inspectable, and constrained-stochastic.
- The simulation remains coherent without internet access, an API key, Ollama, or an LLM.
- The creature's desktop environment uses privacy-minimizing signals and avoids document contents, passwords, keystrokes, private messages, continuous screen capture, and clipboard contents.
- Phase 0 establishes the best foundation and an evidence-backed `CreatureCore → BehaviorIntent → DesktopAdapter` seam before Phase 1 implementation.

## Scope

- Original creature simulation, desktop integration, persistence, behavior, memory, habits, expression, development, testing, and project-owned assets.
- Bounded evaluation of existing desktop-pet infrastructure and behavioral references.

## Non-goals for initial development

- AGI, consciousness claims, neural evolution, reinforcement learning, multiplayer, breeding, battles, cloud accounts, social networking, NFTs, voice conversations, autonomous web browsing, mobile companions, hardware embodiment, and full-screen surveillance.

## Constraints

- Do not use Pokémon or Digimon names, characters, assets, sounds, or designs.
- Prefer structured state and simple deterministic methods before machine learning.
- Keep behavior-first communication; language is optional and subordinate to the simulation.
- Preserve source-code and asset-license distinctions for every external candidate.
