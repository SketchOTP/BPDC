# Conditional Task Packets

Use `.agent/tasks/active/<directive-id>/` only for genuinely complex, long-running, multi-stage, research-heavy, high-risk, or handoff-sensitive work.

Required files when a packet is warranted: `SPEC.md`, `PLAN.md`, `EVIDENCE.md`, and `HANDOFF.md`. Preserve failed and completed packets for provenance; do not create one for ordinary work.
