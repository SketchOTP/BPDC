## Objective

Implement one transient, state-dependent reunion response after an observed user return from IDLE or LOCKED absence, while preserving autonomous behavior and reusing the bounded P7 expression slot.

## Model

- Presence returns expose one-shot `previousState`, `absenceSeconds`, and `returnedFromAbsence` metadata only for IDLE/LOCKED → ACTIVE.
- A five-minute minimum absence suppresses trivial transitions.
- Absence influence is saturating: `1 - exp(-(absenceSeconds - 300) / 3600)` with a maximum weighted contribution of `0.6`.
- Existing bond, innate sociability, juvenile socialization, and current behavior contribute to inspectable reunion affinity.
- Response vocabulary is exactly `ACKNOWLEDGE_RETURN` and `GREET_RETURN`; SLEEP always suppresses reunion expression.
- No absence timestamps, reunion history, schema fields, simulation-time advancement, or state mutations are added.
- P7's single generation-guarded transient restoration timer is shared by reunion and contact responses; the newest legitimate expression supersedes the previous one.
