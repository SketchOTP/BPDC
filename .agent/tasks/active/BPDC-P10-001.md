# BPDC-P10-001 — Continuous Physical Maturation

## Status

`CLOSED_AND_PUBLISHED`

## Objective

Derive continuous physical maturity from existing simulation age and present it through bounded OpenPets scaling.

## Model

- `ageSeconds = max(0, simulationTimestamp - createdAt)`.
- `maturity = clamp(ageSeconds / 1,209,600, 0, 1)`; 1,209,600 seconds is 14 simulated days.
- `sizeFactor = 0.8 + 0.2 * maturity`.
- Maturity and size are derived only; no development state is persisted.
- CreatureCore remains wall-clock and host independent.

## Embodiment

- `OpenPetsAdapter.applyDevelopment()` maps the host-neutral size factor to `pet.setScale()`.
- Factors are bounded to the host range and quantized to `0.01`.
- Repeated unchanged quantized values are suppressed.
- Startup applies scale after restore/reconciliation and before resume embodiment.
- Runtime ticks apply scale only when the quantized value changes.
- Manifest adds exactly `pet:animate`.
