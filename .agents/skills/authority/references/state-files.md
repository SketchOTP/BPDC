# Project-State Update Rules

- `INDEX.md`: update pointers when stage, directive, packet, or accepted outcome changes.
- `PROJECT_GOAL.md`: change only with explicit strategic authorization.
- `PROJECT_PROFILE.md`: update verified durable project facts.
- `CURRENT.md`: mutable current snapshot.
- `DIRECTIVES.md`, `OUTCOMES.md`, `LEARNINGS.md`, `RECORD.md`, `EXTERNAL.md`, `EVIDENCE.md`: append-only after adoption.
- `REPO_MAP.md`: update only when repository understanding materially changes and is verified.
- `tasks/`: use only for complex/long-running/handoff-sensitive work.

Never rewrite or delete history to make the project appear cleaner.
